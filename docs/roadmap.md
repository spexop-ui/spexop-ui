# Roadmap

| Direction | Scope | Status and boundary |
| --- | --- | --- |
| R1 — Agent-native UI Verification | Running URL, route and viewport; real-browser observation; bounded deterministic diagnostics; evidence-bearing agent-readable feedback; explicit rerun | Approved direction; implementation and acceptance still open. CLI/local interface; MCP optional. CSS Export and Build Evidence are not prerequisites. |
| R1.1 — Project consistency | Explore explicit project rules and consistency checks | Conditional on R1 usefulness and reliability; scope and acceptance undecided. |
| R2 — Executable contracts | Explore executable design contracts and their value | Conditional research; no implementation, enforcement or release promise. |

Existing Theme, Foundation Capture, canonical model, provenance, CSS export and build evidence remain preserved, with their historical tests and limitations. They are not evidence that R1 is implemented. Prior Foundation UX and source-to-browser provenance gaps remain open in their original contexts. Source safety and rights gates remain prerequisites for any relevant public release; a roadmap decision does not authorize publishing, deployment or merging.
