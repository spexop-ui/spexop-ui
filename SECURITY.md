# Security Policy

Spexop UI is development source. There is no supported public desktop release or published R1 package at this time. We have no release support matrix or response-time commitment.

## Report a vulnerability

Please do **not** publish exploit details, credentials, personal data, or private project files in an issue, discussion, or pull request. Use GitHub's **Report a vulnerability** / private security advisory flow for this repository if it is available. If that option is unavailable, request a private contact route from the maintainers without including sensitive details in the public request. Keep the report confidential until a maintainer has arranged a private channel.

Include the affected commit or version, reproducible steps, impact, and a minimal safe example. Do not test against other people's systems or data.

The maintainers will assess the report and coordinate any disclosure. Acknowledgment or a technical fix does not by itself mean a release has been approved.
